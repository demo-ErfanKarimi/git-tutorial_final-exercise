# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## Project Structure
- `app.txt`: main application file (demo)
- `.github/workflows/ci.yml`: basic CI pipeline

## How to contribute
1. Open an issue describing the change you want to make.
2. Create a new branch from `main`.
3. Make your changes and commit them with clear messages.
4. Push your branch and open a pull request.
5. Wait for review and address any feedback.
